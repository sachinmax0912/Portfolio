About Me

Offensive security specialist with hands-on penetration testing experience across web applications, e-commerce platforms, and enterprise systems. I test the way real attackers do — manual testing first, tooling second, always guided by OWASP methodology.

My findings include injection flaws, broken encryption, and business-logic race conditions, discovered through Burp Suite, Nmap, Metasploit, and creative attack-vector research backed by Python scripting.

Because I have also worked on the defender's side — triaging alerts, tracing attack vectors through logs and network traffic — my reports don't just show what is broken. They show how it would be detected, and exactly how to fix it.

Penetration Testing Engagements

Business Logic

E-commerce Checkout Security Audit

Online stores lose money when attackers abuse the order and payment flow. I stress-tested 12 checkout, coupon, and payment endpoints with concurrent requests in Burp Suite and caught a critical race condition that allowed duplicate transactions. I delivered a working proof-of-concept and a fix using server-side locking, preventing an estimated $10,000+ in fraud losses before a single order was abused.

Burp Suite Race Conditions OWASP Top 10
Injection

Customer Chatbot Injection Assessment

A chatbot that displays unsanitised user input is an open door to phishing customers. I ran 30+ crafted payloads against a clothing brand's live support chatbot, confirmed a critical HTML injection that allowed arbitrary script execution, and recommended output encoding, input validation, and a Content Security Policy. The fix passed retesting, closing a direct route to customer phishing and XSS attacks.

HTML Injection XSS Input Validation
Cryptographic Failure

Student Portal Authentication & Encryption Review

When a website holds thousands of logins, one weak encryption setting exposes every account. I reviewed a college portal's login flow with Burp Suite and Wireshark and found user credentials travelling in plain text. I flagged it before exploitation and recommended enforced TLS, salted password hashing, and secure session handling, protecting the personal data of thousands of students.

Encryption Analysis Wireshark Authentication
